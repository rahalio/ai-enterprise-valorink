# Valorink — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### CDO / Analytics value office

- As a CDO, I want each use case’s weakest link highlighted, so that I fund remediation instead of another algorithm bake-off.
- As a value office lead, I want finance-attested P&L movement per use case, so that board packs stop citing non-additive percentages as if they stacked.
- As a CDO, I want scale blocked when any chain link is critically red, so that multiplicative reality is enforced.

### Use-case owner / translator

- As a use-case owner, I want to define the business action and KPI before requesting data builds, so that we work business-backwards.
- As a translator, I want AQ training status for the roles that must act on insights, so that adoption is not assumed.
- As a use-case owner, I want predictive outputs bound to a prevention or action playbook, so that churn scores do not sit unused.

### Data scientist / enrichment lead

- As a data scientist, I want domain hypotheses registered as versioned smart variables, so that man + machine enrichment is auditable.
- As a data scientist, I want relevance and freshness rules per use case, so that we do not drown in stale IoT exhaust.

### BU process owner

- As a process owner, I want incentive and workflow redesign tasks tracked alongside the model, so that call-center or maintenance actions actually change.
- As a process owner, I want to reject an “impact delivered” status when my process link is still red, so that false success cannot ship.

### Platform administrator / privacy

- As a privacy officer, I want GDPR/privacy link health to block customer use-case scale, so that impact never outruns lawful basis.
- As an administrator, I want an audit export of link scores, enrichment owners, and attested impacts, so that internal audit can replay the value claim.
- As an administrator, I want to forcibly reopen a closed use case when People/Processes health regresses, so that impact does not silently decay.
